## 🎮 Controls

Nitro Rush 3D is built for maximum immersion using a steering wheel, but supports keyboard setups for accessibility:

| Action | Steering Wheel Input | Keyboard Alternative |
| :--- | :--- | :--- |
| **Steer Left / Right** | Turn Wheel Left / Right | `A` / `D` or `Left` / `Right` Arrow |
| **Accelerate** | Gas Pedal | `W` or `Up` Arrow |
| **Brake / Reverse** | Brake Pedal | `S` or `Down` Arrow |
| **Pause Game** | Start Button | `Esc` |
